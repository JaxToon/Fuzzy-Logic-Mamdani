# Fuzzy Logic (Mamdani)

A from-scratch Mamdani fuzzy inference system, written for a college AI course. It scores how worth buying an item is
("nilai kelayakan") from two inputs, **price** (murah / sedang / mahal) and **quality**, using trapezoidal membership
functions, a fuzzy rule base, inference, and defuzzification. No fuzzy-logic library is used.

```bash
pip install matplotlib pandas tabulate
python fuzzy_logic_peargy.py
```
